# Karan RJ portfolio

A static, responsive portfolio with a local Lottie JSON animation and a GitHub-backed content workflow.

## Preview

From the repository root:

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080/`. The site needs an HTTP server because it fetches its JSON content. No build step or runtime API key is needed.

## Edit content

The site reads `content/*.json` directly. To use the visual editor:

1. Visit [Pages CMS](https://app.pagescms.org/) and sign in with GitHub.
2. Install the Pages CMS GitHub App for `rj-karan/zoroStack`.
3. Open the repository in Pages CMS. Its editor reads [`.pages.yml`](.pages.yml), which is already configured for profile text, projects, reports, CVEs, articles, and achievements.
4. Publish an entry with `published: true`. For a report or article hosted on this site, provide a unique lowercase `slug`, a `body`, and leave `url` empty. To send readers to an external publication, set `url`.

Content edits are GitHub commits. If GitHub Pages is configured to publish this repository, the updated JSON appears on the site after the Pages deployment. Uploaded media is stored in `public/uploads`.

Only verified public work should be added to CVEs, reports, and achievements. Empty arrays intentionally render a clear empty state.

## Files

- `index.html`, `style.css`, `app.js`: portfolio.
- `article.html`, `article.js`: local report and article reader.
- `content/*.json`: editable content.
- `public/animations/signal.json`: original Lottie animation, generated by `node scripts/generate-signal.mjs`.
- `public/vendor/lottie.min.js`: locally hosted lottie-web 5.12.2. The package is MIT licensed.
- `public/karan-rj.jpg`: public GitHub avatar from `https://avatars.githubusercontent.com/u/185403139`.

## Deployment

For the project URL `https://rj-karan.github.io/zoroStack/`, GitHub Pages should publish the root of the branch containing these files. All local asset and content URLs are relative, so the project path works without a custom domain.
